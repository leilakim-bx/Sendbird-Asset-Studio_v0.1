# Source Input Access

Asset Studio can generate infographic image candidates from pasted article text, chart data, or image notes.

## Network Policy

The studio does not import arbitrary URLs. Server-side fetching of public articles, protected pages, or shared links is disabled by security policy.

Allowed external network usage is limited to Pexels image search and Pexels image CDN loading.

## Recommended Source Inputs

Use one of these paths:

1. Paste the article body into **Create from source**.
2. Paste chart data, metrics, or quoted snippets.
3. Add image notes when the article has weak structured data.

If a source exists only as a protected page or internal document, copy the readable text into the studio instead of pasting the URL.
