# Project Docs

This folder keeps product, design, engineering, and reference material out of the repository root.

## Product

- `product/PRD.md` — product goals, scope, workflows, risks, and priorities.

## Design

- `design/STUDIO_DESIGN.md` — editor and studio UI rules.
- `design/ASSET_DESIGN.md` — generated asset visual rules.
- `design/ui-mockups/` — source mockup images.
- `design/font-source/` — licensed font source files, invoices, and license references.
- `design/assets/` — design reference assets that are not loaded by the app at runtime.
- `design/prototypes/` — static design prototypes.

## Engineering

- `engineering/DEVELOPMENT_DESIGN.md` — architecture, routing, state, API, export, and storage design.
- `engineering/source-import-access.md` — protected URL/source import guidance.
- `engineering/infographic-context.md` — internal infographic design context.
